Every way to use Outlook on Linux

Microsoft does not make a Outlook app for Linux. These are the options, and when each one fits.

Why Outlook for Linux

It runs the real Outlook on the web, so Focused Inbox, rules, Copilot, add-ins and calendar work as in a browser. It adds what a browser tab lacks on Linux: a tray icon with the unread count, desktop notifications, mailto: links, separate work and personal profiles, and a hardened, sandboxed app. It is free and open source (GPL-3.0).
