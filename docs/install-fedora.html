Outlook on Fedora, RHEL and openSUSE in one command, as a desktop app with tray icon and notifications.

Download for Linux View on GitHub

Install with dnf

  1. Download outlook-for-linux-<version>.x86_64.rpm (or .aarch64.rpm on ARM) from the latest release.
  2. Install it: sudo dnf install ./outlook-for-linux-*.x86_64.rpm
  3. Start Outlook for Linux from your application menu, or run outlook-for-linux.
  4. Sign in with your work or school account, or your personal Outlook.com account. For both at once, start a second profile: outlook-for-linux --profile=personal --account=personal.

After installing

To open mailto: links in the app, choose Settings › Set as default mail client in the tray or app menu.

Update or remove

The app tells you when a new release is out (Help › Check for Updates). Install the new RPM the same way. Remove it with sudo dnf remove outlook-for-linux.

openSUSE

Use sudo zypper install ./outlook-for-linux-*.x86_64.rpm instead of dnf.
