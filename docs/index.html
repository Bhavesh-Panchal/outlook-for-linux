Outlook on Linux, as a real desktop app

Microsoft does not make an Outlook app for Linux. Outlook for Linux puts Outlook on the web in a proper desktop window, with a tray icon, an unread count, desktop notifications and mailto: links, for work and personal accounts.

  • Accounts: work or school (outlook.office.com) and personal (outlook.live.com); run both at once with profiles.
  • Default mail client: mailto: links open a new message with to, cc, bcc, subject and body filled in. *Settings › Set as default mail client* registers the app with your desktop.
  • Unread count on the tray icon and launcher badge. *Notifications › Disable Badge Count* hides it.
  • Notifications for new mail and reminders, with options to mute sound or turn them off.
  • Downloads of attachments with progress and a notification when done.
  • MQTT / Home Assistant (optional): publish the unread count as a sensor (mqtt.* options).
  • Keyboard: Outlook's own shortcuts keep working; the app does not take Ctrl+Q (*mark as read*) or Ctrl+R (*reply*).

Install Outlook for Linux

Download the package for your system from the latest release, then:

DistributionCommand
Fedora, RHEL, openSUSEsudo dnf install ./outlook-for-linux-*.x86_64.rpm
Ubuntu, Debian, Linux Mintsudo apt install ./outlook-for-linux_*_amd64.deb
Any distribution (AppImage)chmod +x outlook-for-linux-*.AppImage && ./outlook-for-linux-*.AppImage
Any distribution (tar.gz)extract, then run ./outlook-for-linux

Every release lists SHA-256 checksums: sha256sum -c SHA256SUMS --ignore-missing.

Secure by design

  • Electron's sandbox and context isolation stay on for every window; pages cannot reach Node.js.
  • Permissions (notifications, clipboard) only for Microsoft's own pages.
  • Hardened binary: no ELECTRON_RUN_AS_NODE, NODE_OPTIONS, --inspect or remote debugging; sign-in cookies encrypted with your desktop keyring.
  • No telemetry or tracking added by the app. Privacy statement.

Frequently asked questions

Is there an Outlook app for Linux?

Microsoft does not publish one. Outlook for Linux is a free, open-source desktop app by Bhavesh Panchal that runs Outlook on the web in its own window, with Linux desktop integration.

Does it work with work and personal accounts?

Yes. Work or school accounts (Microsoft 365) and personal Outlook.com accounts both work, and you can run them side by side with profiles: outlook-for-linux --profile=personal --account=personal.

Can it be my default mail client?

Yes. In the app, choose Settings › Set as default mail client. mailto: links then open a new message with the recipient, subject and body filled in.

Does Copilot work?

Yes. Copilot Chat and Summarize this email appear as in a browser, if your organisation has them enabled.

Is it official or safe?

It is unofficial and not affiliated with Microsoft. It keeps Electron's sandbox on, sends no telemetry, and its source is public on GitHub.
