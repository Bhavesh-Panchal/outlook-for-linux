One file that runs Outlook on any modern Linux distribution.

Download for Linux View on GitHub

Run the AppImage

  1. Download outlook-for-linux-<version>.AppImage (or -arm64.AppImage) from the latest release.
  2. Make it executable: chmod +x outlook-for-linux-*.AppImage
  3. Run it: ./outlook-for-linux-*.AppImage. AppImageLauncher adds it to your menu.
  4. Sign in with your work or school account, or your personal Outlook.com account. For both at once, start a second profile: outlook-for-linux --profile=personal --account=personal.

Or use the tar.gz

Extract outlook-for-linux-<version>.tar.gz anywhere and run ./outlook-for-linux inside the folder.

After installing

To open mailto: links in the app, choose Settings › Set as default mail client in the tray or app menu.
